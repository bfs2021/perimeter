Copy the token for {{.TokenName}} now. It is shown only once and cannot be recovered. If you lose it, revoke it and create a new one.

Call the API

Claude Code

claude mcp add --transport http perimeter {{.BaseURL}}/mcp --header "Authorization: Bearer {{.Token}}"

Claude Desktop

Add this to claude_desktop_config.json. It needs Node.js for npx.

{
  "mcpServers": {
    "perimeter": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{.BaseURL}}/mcp", "--header", "Authorization:${PERIMETER_AUTH}"],
      "env": {"PERIMETER_AUTH": "Bearer {{.Token}}"}
    }
  }
}
